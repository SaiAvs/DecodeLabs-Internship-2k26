# 🤖 DecodeBot AI

A modern **Rule-Based AI Chatbot** developed using **Python** and **Streamlit** as part of the **DecodeLabs AI Internship**.

DecodeBot is designed to provide an interactive chatbot experience with useful utilities like a smart calculator, random jokes, motivational quotes, interesting facts, and a fun guessing game, all wrapped in a clean dark-themed user interface.

---

# 🚀 Features

- 💬 Interactive Rule-Based AI Chatbot
- 👋 Greeting Responses
- 📅 Current Date
- ⏰ Current Time
- 📆 Current Day
- 😂 Random Programming Jokes
- 💡 Motivational Quotes
- 📚 Interesting AI & Technology Facts
- 🧮 Smart Calculator
  - Addition

- 🎮 Guess The Number Game

# ▶️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/DecodeLabs-Internship.git
```

### 2. Open the Project Folder

```bash
cd DecodeLabs-Internship
```

### 3. Install Dependencies

```bash
pip install streamlit
```

### 4. Run the Application

```bash
streamlit run app.py
```
