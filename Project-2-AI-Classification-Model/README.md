# 🤖 AI Classification Model

A Machine Learning web application built using **Python**, **Streamlit**, and **Scikit-learn** as part of the **DecodeLabs AI Internship - Week 2**.

The application uses the famous **Iris Dataset** to classify iris flowers into three different species based on their measurements.

---

## 🚀 Features

- 🌸 Iris Flower Classification
- 📊 Interactive Dataset Viewer
- 🌳 Decision Tree Classification Model
- 📈 Model Accuracy Evaluation
- 🔍 Real-Time Prediction
- 📋 Dataset Statistics
- 📊 Interactive Visualizations
- 📥 Download Dataset
- 🎨 User-Friendly Streamlit Interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- NumPy

---

## 📂 Dataset

This project uses the **Iris Dataset**, one of the most popular datasets in Machine Learning.

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target Classes

- Setosa
- Versicolor
- Virginica

---

## ⚙️ Machine Learning Workflow

1. Load Iris Dataset
2. Explore and Display Data
3. Split Data into Training and Testing Sets
4. Train Decision Tree Classifier
5. Evaluate Model Accuracy
6. Predict Flower Species
7. Display Results in Streamlit
